# После Пяти

Готовая папка сайта для загрузки на GitHub.

## Запуск

Откройте `index.html` в браузере. Сайт не требует сборки и использует Google Fonts.

## Структура

- `index.html` — разметка страницы
- `styles.css`, `redesign.css`, `refine.css` — стили
- `script.js` — каталог, модальное окно, форма и интерактивы
- `assets/` — все изображения сайта

Для GitHub Pages загрузите содержимое этой папки в репозиторий и включите Pages из ветки `main`, папки `/root`.
